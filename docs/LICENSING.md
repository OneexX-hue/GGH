# Лицензии зависимостей

Проверено построчно на реальных LICENSE-файлах в этой сессии разработки
ТЗ (не по описаниям из поиска). Перепроверять при использовании — лицензии
меняются (пример: Matrix Synapse сменил Apache-2.0 на AGPL в 2023 году без
изменения кода).

**Правило для Claude Code:** перед `npm install` / `pip install` / любым
добавлением стороннего кода — искать пакет в таблице ниже. Если его нет —
самостоятельно найти и прочитать файл LICENSE в репозитории пакета,
добавить запись сюда, и только потом использовать. Не устанавливать
GPL/AGPL/сильный copyleft без явного одобрения человека — сообщить о
находке и подождать решения, а не устанавливать «на всякий случай, потом
уберём».

## Как добавлять новые записи

1. Найти официальный репозиторий пакета
2. Открыть файл `LICENSE` (не README — там иногда лицензия указана неточно, как выяснилось на примере Nomeroff Net)
3. Проверить, нет ли отдельной лицензии для части кода (пример: Rocket.Chat — MIT в целом, но `ee/`-директория отдельно)
4. Добавить строку в соответствующую таблицу выше с датой проверки
5. Если сомнение — переспросить пользователя, не решать самостоятельно в пользу «разрешено»
