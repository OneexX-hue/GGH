# Secret Chat UI Kit

Статическая реализация дизайна «Секретный чат» по референсу: мобильный экран
в корпусе телефона, десктоп-приложение (список чатов + диалог + панель
информации) и блок ключевых функций.

Без сборки, без зависимостей, без внешних запросов — открывается как обычный
HTML-файл.

## Запуск

```bash
python3 -m http.server 8080
```

Затем откройте <http://localhost:8080>. Файл `index.html` открывается и
напрямую из файловой системы.

## Структура

```
index.html              разметка всех трёх блоков + инлайновый SVG-спрайт иконок
src/css/fonts.css       @font-face для локального Inter
src/css/tokens.css      дизайн-токены: цвета, радиусы, отступы, типографика
src/css/app.css         вся верстка и адаптив
src/js/app.js           фильтры, поиск, переключение чата, отправка, таймер
assets/icons/           37 иконок (те же контуры, что в спрайте), currentColor
assets/avatars/         аватары собеседников и портрет для панели информации
assets/decor/           объёмные иконки для карточек функций
assets/bg/              «созвездие» — фон полотна сообщений
assets/fonts/           Inter (latin + cyrillic), два woff2
docs/palette.json       палитра в HEX
docs/reference.jpeg     исходный визуальный референс
tools/gen-*.py          генераторы SVG-ассетов (иконки, аватары, декор, фон)
```

## Иконки

Иконки живут в двух видах и генерируются из одного источника —
`tools/gen-icons.py`:

- инлайновый `<symbol>`-спрайт в `index.html` — используется страницей,
  наследует цвет через `currentColor` (внешние ссылки в `<use>` Chrome не
  поддерживает, поэтому спрайт именно инлайновый);
- отдельные файлы `assets/icons/*.svg` — для переноса в свой проект.

После правки генератора запустите `python3 tools/gen-icons.py` и вставьте
свежий спрайт в `index.html`.

## Интеграция

Для существующего проекта перенесите `src/css/tokens.css`, `src/css/app.css`,
`src/css/fonts.css` вместе с `assets/` и нужные блоки разметки из
`index.html`.

Аватары подключены обычными `<img>` — чтобы поставить настоящие фотографии,
достаточно заменить файлы в `assets/avatars/` или атрибут `src`.

## Что это

Реконструкция по изображению, а не исходники оригинального макета. Размеры,
цвета и раскладка подобраны под референс и оформлены как поддерживаемая
дизайн-система. Аватары на референсе — фотографии; здесь на их месте
векторные силуэты с контровым светом, повторяющие тональность оригинала.
