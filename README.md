# Квест Платформа

Платформа для городских квестов: регистрация команд, задания с кодами, серверный
таймер, панель организатора и оценка качества. Работает как **веб-приложение**,
**Android**- и **iOS**-приложение поверх одного API.

Полная спецификация и архитектурные решения — [`SPEC.md`](./SPEC.md).

## Быстрый старт

```bash
pnpm install
pnpm run dev
```

Одна команда поднимает API и веб вместе и печатает адреса:

```
  Игроки        http://localhost:21234
  Организатор   http://localhost:21234/admin
  Токен организатора:  dev-secret
```

При первом запуске API создаёт `apps/api/data/quest.db`, применяет миграции
и заводит демо-событие `city-quest` с 10 заданиями и тремя кодами качества.
`Ctrl+C` останавливает всё.

Токен организатора берётся из `ADMIN_TOKEN`; если она не задана, подставляется `dev-secret`.
Для настоящей игры задайте свой:

```bash
ADMIN_TOKEN=длинный-случайный-секрет pnpm run dev
```

### Проверка с телефона

`pnpm run dev` печатает второй блок адресов — по локальной сети:

```
  С телефона в том же Wi-Fi:
  Игроки        http://192.168.1.42:21234
```

Откройте этот адрес на телефоне, подключённом к тому же Wi-Fi. Так квест
проверяется в том виде, в каком его увидят участники: с телефона, с реальной
геолокацией и на ходу. Компьютер при этом работает как сервер — держите
`pnpm run dev` запущенным.

### Пробная игра за пять минут

1. Откройте `/admin`, введите токен, нажмите **Старт**
2. В другой вкладке (или на телефоне) откройте `/` и зарегистрируйтесь
3. Коды заданий видны в админке в разделе «Задания» — введите любой
4. Проверьте **Пауза** / **Продолжить**: таймер замирает, коды не принимаются
5. Нажмите **Стоп** — игрок увидит финальный экран, вы увидите табло

Коды демо-заданий: `СТАРТ`, `1147`, `КНИГА`, `24`, `ДУБ`, `РЕЛЬС`, `АНТРАКТ`,
`ВОЛНА`, `ВЫСОТА`, `ФИНИШ`. Коды качества: `КАЧ10`, `КАЧ5`, `КАЧ3` — доступны
только на заданиях со звёздочкой и только после того, как задание сдано.

Начать с чистого листа: удалить `apps/api/data/quest.db` либо нажать **Сброс**
в админке (он попросит ввести название события и сохранит снимок итогов в архив).

### Запуск по отдельности

```bash
ADMIN_TOKEN=secret pnpm run dev:api   # только API,  :8080
pnpm run dev:web                       # только веб,  :21234
pnpm --filter @workspace/quest-mobile run dev   # мобильное приложение
```

## Как проходит игра

Организатор нажимает **Старт**. Дальше игра идёт до конца таймера или до **Стоп** —
команда, закрывшая все задания, ждёт остальных, автоматического финиша по первому
месту нет.

**Игрок не видит баллов и мест — ни во время игры, ни после.** У сданных заданий
номинал скрыт, суммы нет вовсе. Это сделано не скрытием на экране, а отсутствием
полей в API: подсмотреть счёт в обход интерфейса нельзя. Табло, места и CSV
доступны только организатору — итоги он объявляет сам.

По завершении игрок видит нейтральный экран: сколько заданий закрыл и что итоги
объявит организатор.

Итоги сохраняются навсегда. Удалить их может только **Сброс**, который требует
ввести название события и перед удалением кладёт снимок табло в архив.

## Команды

| Команда | Что делает |
|---|---|
| `pnpm run typecheck` | Проверка типов по всем пакетам |
| `pnpm run test` | Тесты (ядро, API) |
| `pnpm run build` | Сборка веба и CJS-бандла API |
| `pnpm run gen:openapi` | Перегенерация `lib/api-spec/openapi.yaml` из Zod-схем |
| `pnpm run dev` | API и веб вместе, с адресами и токеном |
| `pnpm run dev:api` / `dev:web` | По отдельности |

## Структура

```
apps/api      Express 5 + SQLite (node:sqlite)
apps/web      Vite + React 19 + Tailwind v4 + Wouter + TanStack Query
apps/mobile   Expo (React Native), expo-router, камера/QR, геолокация
lib/core      Zod-схемы, таймер, гео, офлайн-очередь — общие для всех клиентов
lib/db        Схема БД, миграции, мапперы строк
lib/api-client Транспорт + хуки TanStack Query — общие для веба и мобилки
lib/api-spec  Генератор openapi.yaml
```

## Переменные окружения

**API**

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `ADMIN_TOKEN` | — (обязательна) | Секрет панели организатора |
| `PORT` | `8080` | Порт |
| `DB_PATH` | `data/quest.db` | Файл SQLite |
| `ALLOWED_ORIGINS` | `*` | Список origin через запятую |

**Веб** — `VITE_API_URL` (пусто = прокси Vite), `VITE_EVENT_SLUG` (`city-quest`).

**Мобилка** — `extra.apiUrl` и `extra.eventSlug` в `apps/mobile/app.json`.
Для сборок — `EXPO_PUBLIC_API_URL` в `eas.json`.

## Сборка мобильных приложений

Локально приложение запускается через Expo Go / dev-client. Для магазинов:

```bash
npm install -g eas-cli && eas login
cd apps/mobile
eas build --platform android --profile preview   # APK для внутренней раздачи
eas build --platform ios --profile production    # требует Apple Developer Program
```

Понадобятся учётные записи: Apple Developer Program (99 $/год) и Google Play
Console (25 $ разово). Перед сборкой заменить `bundleIdentifier` и `package`
в `app.json` на свои.

## Требования

Node.js **22.5+** — используется встроенный `node:sqlite`, внешних зависимостей
для БД нет. На Node 22 модуль помечен экспериментальным и печатает предупреждение
при старте; это ожидаемо.
